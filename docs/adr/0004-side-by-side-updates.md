# 0004. 更新はバージョン別フォルダの切り替えで行う

- 状態: 採用（2026-11-07。Velopack 等の既製品で同じ性質が得られるなら P5 で置き換えを検討）

## 背景

仕様 6.3 は、更新途中の失敗や新バージョンの起動確認失敗のときに、直前の動作していたバージョンへ戻すことを求めている。MSI のメジャーアップグレードだけでは旧版が消えるため、この復旧を保証しにくい。

## 決定

- アプリ本体はユーザー単位のフォルダに `app-x.y.z\` としてバージョンごとに並べ、固定の起動スタブが「現行版」を指す。
- `pa-updater` は新版を展開し、起動確認に成功したら指す先を切り替える。失敗したら切り替えない。古い版は 1 つだけ残す。
- 初回導入とアンインストールは WiX Burn バンドルで行う。アンインストール時の「設定を保持 / 全削除」の選択は Burn の UI で出す。
- 更新マニフェストは Ed25519 で署名し、公開鍵をアプリに埋め込む。ダウンロードしたパッケージは Authenticode も検証する。

## 影響

ロールバックが「指す先を戻す」だけになる。代わりに起動スタブと pa-updater を自前で保守する必要がある。
